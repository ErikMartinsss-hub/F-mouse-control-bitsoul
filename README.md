# BitSoul Mouse Control

Programa para desabilitar botões do mouse no Windows.

## Funcionalidades

- Desabilita seletivamente os botões do mouse:
  - Botão direito
  - Botão do meio
  - Botão lateral 1 (Voltar / Back)
  - Botão lateral 2 (Avançar / Forward)
- Salva as configurações automaticamente
- Inicia junto com o Windows (opcional)
- Fica na bandeja do sistema (system tray)

## Como usar

1. Execute o programa
2. Desmarque os botões que deseja desabilitar
3. Clique em **"Aplicar e Esconder"**
4. O programa será minimizado para a bandeja do sistema
5. Para reabrir as configurações, clique duas vezes no ícone da bandeja ou clique com o botão direito e selecione **"Abrir Configurações"**

## Como desabilitar a inicialização automática

Abra as configurações, desmarque a opção *"Iniciar automaticamente com o Windows"* e clique em **"Aplicar e Esconder"**.

## Requisitos

- Windows (x64)
- .NET 8.0 ou superior
